# Большие книги в EPUB

Руководство по сборке книг, где заголовков тысячи: собраний стихов, сутр, комментариев с
пронумерованными фрагментами. Обычная книга в этих настройках не нуждается.

## Что ломается без настройки

Один входной файл даёт один xhtml-документ, каким бы он ни вырос. Том Махабхараты, где
каждый стих — заголовок, собирался в **один документ на 16.8 МБ** с **12 142 пунктами**
в навигации читалки. Читалка загружает документ целиком, поэтому такая книга открывается
с задержкой и листается рывками, а оглавление, где главы перемешаны со стихами,
бесполезно.

## Быстрый рецепт

```bash
telegraph-publisher epub -f book.md -o book.epub -a "Автор" -t "Название" \
  --split-at 2 --toc-depth 2
```

Книга режется на документы по главам, навигация показывает только главы, а список стихов
появляется в начале каждой главы сам — иначе, спрятав их из навигации, до них было бы
не добраться.

Результат на томе «Сабха-парва»: 120 документов не больше 184 КБ, 120 пунктов навигации
вместо 4 656.

## Как выбрать уровень

`--split-at` и `--toc-depth` принимают уровень заголовка. Он зависит от разметки книги, а
она у всех разная: где-то главы — это `##`, где-то `###`. Посчитайте заголовки по уровням
и возьмите самый глубокий, чей список ещё обозрим (несколько сотен пунктов):

```bash
grep -c '^## '  book.md    # глав
grep -c '^### ' book.md    # стихов
```

Если `##` почти нет, а `###` — тысячи, книга размечена на уровень глубже: берите `3`.

## Опции

| Опция | По умолчанию | Назначение |
|---|---|---|
| `--split-at <n>` | не резать | Резать книгу на документы по заголовкам уровня `n` и выше |
| `--toc-depth <n>` | все заголовки | Глубина навигации читалки (`toc.ncx`) |
| `--chapter-toc <pos>` | `auto` | Список заголовков главы в её тексте: `start`, `end`, `none`, `auto` |
| `--chapter-toc-depth <n>` | без ограничения | Глубина этого списка |
| `--book-toc <pos>` | выключено | Отдельная страница с оглавлением всей книги: `start` или `end` |
| `--book-toc-depth <n>` | `--toc-depth`, иначе 2 | Глубина этой страницы |
| `--toc-title <t>` | «Содержание» | Заголовок оглавления |

## Два оглавления и связь между ними

В EPUB их два, и они отвечают друг за друга:

* **навигация читалки** (`toc.ncx`) — панель, которую читалка показывает по кнопке;
* **оглавление в тексте** — обычный список ссылок внутри документа.

`--chapter-toc auto` (по умолчанию) связывает их: пока `--toc-depth` прячет заголовки главы
из навигации, список в тексте добавляется автоматически, потому что иначе до этих
заголовков не добраться. Когда навигация показывает всё, список не добавляется — он лишь
повторял бы её.

Страница `--book-toc` дублирует навигацию намеренно. Она нужна там, где навигации нет:
чтение распакованных файлов в браузере, печать, конвертация в другие форматы. В обычной
читалке она чаще лишняя, поэтому по умолчанию выключена.

## Что происходит с якорями при разбиении

Заголовок, с которого начинается часть, становится её `<h1>` и **сохраняет свой прежний
якорь**. Ссылка вида `[см.](#глава-5)`, написанная до разбиения, продолжает работать.
Ссылки между файлами ведут на тот документ, которым файл начинается.

## Ограничения

* Резать можно только по заголовкам. Книга без заголовков верхнего уровня останется одним
  документом — тогда возьмите уровень глубже.
* Разбиение не меняет порядок чтения: документы идут в spine в том же порядке, что и текст.
